# WDD430 Portfolio

A personal developer portfolio built with Next.js, TypeScript, React, and Tailwind CSS.

## Getting Started

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open http://localhost:3000 in your browser.

## Features

- Responsive portfolio homepage
- About page
- Reusable React components
- Next.js App Router navigation
- Simple API route

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS

## Deployment

The application will be deployed using Vercel.
